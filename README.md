## 📌 About the Project

The **JavaScript Counter App** is a simple interactive web application built using HTML, CSS, and JavaScript. Users can increase or decrease a number, while the application saves the latest count in the browser using Local Storage.

This project helped me strengthen my JavaScript fundamentals and understand how user interactions can dynamically update a web page.

## ✨ Features

- ➕ **Increment:** Increase the counter by one.
- ➖ **Decrement:** Decrease the counter by one.
- 💾 **Persistent Storage:** Save the current count in browser Local Storage.
- 🔄 **Refresh Persistence:** Restore the saved count after refreshing the page.
- 🎨 **Custom UI:** Styled counter card, colored buttons, rounded corners, and box shadow.
- ⚡ **Instant Updates:** Update the displayed number immediately after each click.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Structure of the application |
| CSS3 | Styling, colors, spacing, and shadows |
| JavaScript | Counter logic and event handling |
| DOM Manipulation | Updating the displayed count |

## 🚀 Getting Started

### Prerequisites

- A modern web browser.
- A text editor such as Visual Studio Code.

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/k-siddhartha-ai/javascript-counter-app.git
   ```

2. Navigate to the project directory:

   ```bash
   cd javascript-counter-app
   ```

3. Open `index.html` in your browser.

No additional packages or backend server are required.
